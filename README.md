# アプリケーションを作成した背景
ベンチプレス100kgを目標にトレーニングを続ける中で、情報収集を行ったが、YouTubeやSNSには上級者向けの内容が多く、70〜90kg帯の中級者に適した情報はほとんど見つからなかった。また、ノートやスマホのメモで記録しても振り返りにくく、自身の成長過程が見えづらいことに課題を感じていた。
そこで、同じレベルの人がトレーニング記録とフォームの状態を管理し、成長の流れを可視化できるアプリが必要だと考え、本アプリの作成に至った。
中級者が「次に何をすべきか」を判断できる環境をつくることを目的としている。
